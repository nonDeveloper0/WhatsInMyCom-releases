# 💽 What's in my COM?

내 PC의 드라이브와 폴더를 훑어 **무엇이 공간을 차지하는지 한눈에 보여 주고**, **내용이 똑같은 중복 파일을 찾아 주는** Windows 앱입니다.

이 저장소는 What's in my COM?의 설치 파일과 업데이트를 배포하기 위한 공간입니다. 소스코드는 포함되어 있지 않습니다.

## ✨ 주요 기능

- **용량 지도:** 폴더 트리와 트리맵으로 큰 폴더·파일을 몇 번의 클릭으로 찾습니다. 확장자별 통계도 함께 보여 줍니다.
- **빠른 스캔:** NTFS 드라이브는 관리자 승인(UAC) 한 번으로 빠르게 스캔하고, 승인하지 않으면 일반 스캔으로 진행합니다. 연결된 모든 드라이브를 한 번에 스캔할 수 있습니다.
- **중복 파일 찾기:** 크기 → 부분 비교 → 전체 비교 3단계로, 내용이 정말 같은 파일만 중복으로 표시합니다. 남길 파일을 추천하고, 정리는 **휴지통으로만** 보냅니다.
- **파일 이름 검색:** 스캔한 드라이브 전체에서 파일 이름을 바로 검색합니다(와일드카드·정규식 지원).
- **자동 반영:** NTFS 드라이브의 변경 사항을 몇 초 안에 트리와 검색에 반영합니다.
- **개인정보:** 모든 분석은 PC 안에서만 이뤄지며, 네트워크로 아무것도 보내지 않습니다.

## 🛠 설치 방법

1. 위 링크에서 설치 파일을 다운로드합니다.
2. 다운로드한 `whatsinmycom-windows-x64-setup.exe`를 실행합니다.
3. "Windows의 PC 보호" 창이 나타나면 **추가 정보 → 실행**을 누릅니다. (아직 코드 서명이 없는 테스트 버전이라 표시되는 안내입니다.)
4. 설치가 끝나면 시작 메뉴에서 **WhatsInMyCom**을 실행합니다.

- 현재 사용자 계정에만 설치되며, 설치에 관리자 권한이 필요하지 않습니다.
- 새 버전은 같은 방법으로 설치 파일을 실행하면 기존 설치를 덮어써 업데이트합니다.
- 창을 닫으면 트레이로 숨겨집니다. 완전히 종료하려면 트레이 아이콘 메뉴에서 **종료**를 누르세요.

## 📢 안내사항

- 현재 개발 중인 테스트 버전으로, 일부 오류가 발생할 수 있습니다.
- 앱은 사용자가 확인하기 전에는 어떤 파일도 지우지 않습니다.
- 새로운 버전은 GitHub Releases를 통해 배포합니다.
- 설치 파일은 릴리스에 포함된 `SHA256SUMS.txt`로 무결성을 확인할 수 있습니다.
